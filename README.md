# King House Inmobiliaria — Landing Page

Landing page para Andrés García / King House Inmobiliaria.

## Cómo publicar en GitHub Pages (gratis)

1. Ve a [github.com](https://github.com) y crea una cuenta gratis
2. Clic en **"New repository"**
3. Nombre del repositorio: `king-house` (o el que quieras)
4. Marca **"Public"**
5. Clic en **"Create repository"**
6. Sube el archivo `index.html` arrastrándolo
7. Ve a **Settings → Pages**
8. En "Source" selecciona **"Deploy from a branch"**
9. Rama: **main**, carpeta: **/ (root)**
10. Clic en **Save**

En 2 minutos tu página estará en:
**https://TU-USUARIO.github.io/king-house**

Ese enlace lo compartes en Facebook, WhatsApp, Instagram, etc.
